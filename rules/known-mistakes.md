# Known mistakes

Data for `scripts/us_check.py`, which reads it; no agent loads this file. Each row is a mistake books often
make. `us_check.py BOOK [N]` flags every match in a book whose PLAN.md title, `for:` line or BOOK.md names one
word of the subject (`*`: every book), unless a `<!-- checked: -->` mark sits within three lines after it.
`us_check.py --mistakes WORDS` prints the truths for a facts card; `us_check.py --learn` adds a row (it refuses
a pattern that does not compile, a truth that matches its own pattern, and a pattern already here).

The pattern is a Python regular expression in backticks, matched without regard to case against each prose
paragraph and each code line, whitespace runs collapsed to one space. Write `\|` for the `|` of a regular
expression (a bare `|` ends the cell). A book may keep its own rows in the same format in its MISTAKES.md.
