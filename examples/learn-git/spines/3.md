# Chapter 3 spine: Exploring history

Picture: the photo album of §1.2, now browsed rather than filled: the log is the album's contents page, `git show` holds one page up close, `HEAD~2` counts pages back from the newest, a diff lays two pages side by side, a tag is a sticky label on a page. Where it stops: Git stores whole snapshots but shows you differences it works out on the spot.
