|---|---|

| `references/plan-patterns/language.md` | the book's `kind:` is `language` |
| `references/plan-patterns/tool.md` | the book's `kind:` is `tool` (also read `rules/tool-books.md`) |

| `references/plan-patterns/system.md` | the book's `kind:` is `system` |

| `references/facts.md` | writing `PRACTICES.md`: the one lookup per book |
| `references/checklist.md` | just before showing the plan to the learner |
| `assets/PLAN.template.md` | starting `book/<book>/PLAN.md` |
