# us-review references

Read the one the step needs, not all of them.

| File | Read when |
|---|---|
| `risk-review.md` | at the start of every review pass: how to settle each item `--risks` lists, cheapest way first, and when to stop |
| `verify-by-kind.md` | an item cannot be settled by PRACTICES.md and you must decide what counts as checked for this book's `Kind:` (read only that kind's part) |
| `one-read.md` | step 4, after the risk list: the single read of the chapter and the five things it hunts for, with examples |
| `rubric.md` | at the end of the pass, to write the one-line score in REVIEW.md |
| `reader-reports.md` | the reader says something is wrong, does not work, or lost them |
| `../assets/REVIEW.template.md` | writing the chapter's lines in `book/<book>/REVIEW.md`, or a reader-report line |

The content rules themselves are in `rules/writers-guide.md`; the markers (`risk`, `unrun`, `danger`, `code`) in `rules/book-standard.md`. These files do not repeat them.
