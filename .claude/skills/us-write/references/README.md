# us-write: references and assets

Read the guide (`rules/writers-guide.md`), the book's `BOOK.md` and `PRACTICES.md`, then one kind file and one sample. The rest only when a step needs it.

| File | Read it when |
|---|---|
| `kinds/language.md` | `kind: language`; read the one kind file of the book before writing |
| `kinds/tool.md` | `kind: tool` |
| `kinds/framework.md` | `kind: framework` |
| `kinds/system.md` | `kind: system` (operating systems, networks, databases, architecture, algorithms, theory) |
| `kinds/skill.md` | `kind: skill` (professional practice that is not programming) |
| `samples/<kind>.md` | before writing a book: the one sample for its kind, read in full; it sets the voice and the depth (`samples/README.md` lists them) |
| `sections/concept.md` | unsure of the shape of a section that introduces one idea |
| `sections/mechanism.md` | unsure of the shape of a section about how something happens, in order |
| `sections/procedure.md` | unsure of the shape of a section that teaches a job in steps |
| `sections/worked-case.md` | unsure of the shape of a section that teaches judgement through a weak and a better version |
| `sections/short.md` | writing a plan section of kind `short` |
| `sections/practice.md` | writing the practice section that closes a chapter |
| `explaining.md` | an explanation feels flat: choosing a picture, saying where it breaks, introducing terms |
| `depth.md` | the check calls a lesson too short, or a section reads like a list of facts: the four usual gaps and what to add |
| `exercises.md` | writing Check yourself questions or practice tasks; setting the chapter project for the book's kind |
| `risk.md` | unsure whether a passage gets a `<!-- risk: why -->` note |
| `checklist.md` | the chapter is written and checked; before adding the `BOOK.md` line and handing to review |
| `../assets/chapter-start.md` | starting a new chapter file: copy it, fill the numbers and titles from PLAN.md, keep the fence language of the book's `run:`; `us_index.py` fills the contents block |
