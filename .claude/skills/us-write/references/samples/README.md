# Samples to write from

One finished section for each kind of subject. Before writing a book, read the one sample that matches the book's
`kind:`. Copy its voice, its depth (how long it stays with one idea, how it walks a case and then changes one thing),
its honesty about where a picture stops being true, and the way its questions make the reader do something. The
first three were written when every section had the same fixed headings ("The question", "The picture"...): do not
copy those headings. Name your own after your content, as `system.md` and `skill.md` do.

| Kind | Sample | From |
|---|---|---|
| language | `language.md` | *Learn C the Jojo way*, section 8.2, pointers |
| tool | `tool.md` | a Docker book, section 5.2, the container's writable layer |
| framework | `framework.md` | a Spring Boot book, section 7.1, the first REST controller |
| system | `system.md` | a database book, section 6.2, the lost update |
| skill | `skill.md` | a book for new testers, section 3.2, a bug report |
