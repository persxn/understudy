# us-teach references

| File | Read when |
|---|---|
| `lesson-by-kind.md` | a lesson starts in a book whose `kind:` you have not taught this session: what the learner does and what a good check question looks like for a language, tool, framework, system or skill |
| `questions.md` | you are unsure what to ask, or how to answer a wrong, half-right or "don't know" reply |
| `when-stuck.md` | the learner has tried and is not moving: the hint ladder, worked through, and the idea-in-two-lines limit |
